Два выбора как накатывать проект:
1 - Expo (ваш компьютер и ваш телефон находятся в одной сети)
2 - Android Studio

для создания проекта: npx create-expo-app@latest название(client) или npm create-expo-app@latest название(client)

node_modules - не переносим для сдачи или других компьютеров
Чтобы потянуть зависимости, которые устанавливали перед запуском проекта:
npm i 
npm - менеджер пакетов
npx - запускает пакеты без постояннной установки

create-expo-app  - генератор react native проекта на expo
expo - для быстрых приложений, интерфейса, игр, прототипов
клиентских приложений

react native cli  - без expo, когда нужен полный контроль над android/ios
нативной частью свои srift модули java, kotlin, сложные sdk
специфичная интеграция

Для того, чтобы проверить проект, который мы создаём на телефон надо установить Expo Go с Play Market'а 
(телефон и компьютер должны находиться в одной сети Wifi и т.д)

Для запуска: npm run start 
             npm expo start

Основная папка сбора app/ :
index - главный экран
explore - второй экран
_layout - общий для всех навигаций

папка components/ :
сюда вкладываем свои переиспользуемые компоненты *.tsx
все файлы, что создаём (компоненты) всегда должны быть с большой буквы


Как создавать стилистику для тэгов(объектов):
создаётся  отдельная константа const style = StyleSheet.create({
    объект:{
        ключ стиля: значение
    }
})

в самом тэге <Text style = {style.hero}> текст </Text>


Когда создали компонент нам нужно вывести его либо в отдельный блок, если он является дочерним,
либо вывести его сразу на прямую на экран.
Мы идём в index.tsx - это является нашей точкой сбора компонентов


Основные компоненты:
1 - Невидимый контейнер для сбора (коробка)
    <View> </View> - любые другие компоненты
    Используется для обёрток карточек секций экранов.
2 - <Text> </Text> - любой текст
3 - <Image> source = {{uri:путь до картинки (либо с бэкэнда, либо https:....)}} </Image> - одинарный тэг
    Используется для картинок, обязательно передаём ширину и высоту.
4 - Используем press для кликабельных элементов карточек, кнопок и т.д.
    <Pressable onPress{() => вызов функции}>
       <Text> Нажми меня </Text>
    </Pressable>
5 - Простая стандартная кнопка
    <Button title="Нажми меня" onPress{() => вызов функции}> </Button>
    Используется для более красивогшо интерфейса и отзывчивости. Лучше делать через Pressable


Поле ввода:
<TextInput placeholder="Поисковик"/>

Если контента больше, чем позволяет экран:
<ScrollView> Много контента </ScrollView>

Для списков, если элементов много:
const data = [
    {id:1,title:"Товар 1"},
    {id:2,title:"Товар 2"},
]

<FlatList 
 data={data}
 keyExtracor={(item) => item.id} renderItem ={({item}) => <готовый пред.созданный компонент, либо тэг> {item.title} <закрытый тэг>}
/>



Стили:
Все стили пишутся через обращение к объекту. Инлайн стили максимум только для картинок.
Все остальные через StyleSheet.create({

})

FlexBox - сетка для контента. По умолчанию весь контент в колонку.
flexDirection:"column" - контент в колонку,
flexDirection:"row" - контент в строку.

Выравние элементов по главной оси:
justifyContent:'center',
justifyContent:'flex-start' - в начало,
justifyContent:'flex-end' - в конец,
justifyContent:'space-between' - расстояние максималтное между элементами,
justifyContent:'space-around' - расстояние вокруг,
justifyContent:'space-evenly' - равномерное расстояние.

Выравнивание элементов по поперечной оси:
alignItems:'center'

Само свойства flex у элементов:
flex:1 - означает занять все доступные места. Например, у главного контейнера, в котором другие элементы можно поставить.
flex:1 - если не поставить 1, то flex может занимать высоту своего содержимого.
