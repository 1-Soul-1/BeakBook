Запустить и включить автозагрузку
sudo systemctl start gunicorn
sudo systemctl enable gunicorn
sudo systemctl status gunicorn (проверяем что статус был activate(runing))

как получили все active - устанавливаем nginx
sudo apt update
sudo apt install nginx

создаем конфигурацию nginx
sudo nano /etc/nginx/sites-available/my_project -> sudo nano /etc/nginx/sites-available/BeakBook

прописываем конфигурацию настройки:
server {
    listen 80;
    server_name ваш_белый_ip_адрес;

    location /static/ {
        root /home/myproject;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/home/myproject/myproject.sock;
    }
}

превратить в - 

server {

    location / {

    }
}



Активируем конфигурацию:
sudo ln -s /etc/nginx/sites-available/BeakBook /etc/nginx/sites-enabled
sudo nginx -t (проверить нет ли ошибок в config)
sudo systemctl restart nginx
